# MapleLegends 品克缤攻略

本地打开入口：`index.html`。顶栏在 **Host** 与 **成员** 之间切换。

| 页面 | 内容 |
|------|------|
| `pink-bean-animations-guide.html` | 给 host：编制、动画、技能表、跑团口令 |
| `pink-bean-member.html` | 给成员：进本、听令、停手 |
| `index.html` | 选择入口 |

来源：[Pink Bean Animations Guide](https://forum.legends.ml/index.php?threads/pink-bean-animations-guide.35740/)
