# MapleLegends Boss 攻略（PB / BGA）

本地打开入口：`index.html`（或分别打开下方页面）。顶栏可在 **品克缤（PB）** 与 **保镖 A（BGA）** 之间切换。

| 页面 | 内容 |
|------|------|
| `pink-bean-animations-guide.html` | 品克缤动画/编制合并稿 |
| `bodyguard-a-bga-guide.html` | 保镖 A（BGA）综合预览稿 |
| `index.html` | 选择入口 |

## 来源

- PB：[Pink Bean Animations Guide](https://forum.legends.ml/index.php?threads/pink-bean-animations-guide.35740/)
- BGA：[Corsair BGA guide](https://forum.legends.ml/index.php?threads/corsair-bga-guide.59643/) · [Change BGA](https://forum.legends.ml/index.php?threads/change-bga.59456/) · [图鉴 Bodyguard A](https://legends.ml/lib/monster?id=9400112)

BGA 论坛没有与 PB 同级的完整动画主帖，BGA 页为现有公开帖整理预览。
