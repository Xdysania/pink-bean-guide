保镖 A 攻略 Bodyguard A / BGA

MapleLegends 新叶城（NLC）保镖战。口语常把整场叫 BGA，实际会陆续打到保镖 A、保镖 B、老大（The Boss）与女老板（Anego）。

本页侧重技能与打法要点。机制以现行版本为准；细节以当周主持人（host）口令为准。
简称对照： 保镖 A（BGA）、保镖 B（BGB）、老大（The Boss）、 女老板（Anego / Female Boss）、 pin（把怪顶/压在角落）、cleave（群攻）、 鸟笼/鸟（Homing Beacon / bird，船长）、章鱼（Octopus）。

TL;DR

  • 现行：近战 cleave 更吃香；远程仍可打。
  • 核心：把怪 pin 在角落，别让人站进保镖 A 出拳范围；脱 pin 时近战冲上去重新 pin，输出先停手。
  • 优先点杀保镖 A：它决定老大刷新节奏，还会晕队。
  • 女老板：可与大群分开用单体点掉；船长鸟笼点到时极快。
  • 编制：常见 3–4 人；cleave 核心 + 能 pin 的近战；神射手（BM）远程里相对吃香。

Boss 技能说明（重点）

保镖 A/B 同时刷新；老大在 A+B 合计掉血到约一半后出场，不是等 BGB 死光。全场无触碰；单下伤害上限约 11.5k；仍有把血蓝打成 1/1 的技能。

保镖 A（BGA）

技能 / 现象效果应对
近战拳 / 踢（贴身） 贴身危险；有人进攻击圈会诱发出拳。短距拳可带晕（Stun）。 pin 在角落后远程在射程外打；未 pin 住时输出停手，近战去重新 pin。
晕（Stun） 仍有晕，频率不高（大约 1 次/分钟 量级）。 pin 位可能吃晕；晕住时队友勿乱打导致脱 pin。
属性 弱毒（Poison）。击退阈值约 5 万。 毒系有发挥；pin 需要够击退。

保镖 B（BGB）

技能 / 现象效果应对
弹雨 / 子弹雨（Bullet rain） 头顶砸弹，单次大约 ~10k。船在弹雨下耐久有限。 船长可用下马吃弹 / 金弹无敌帧续船；其他人注意走位与吃药。
金色子弹（Golden bullet） 被金弹打中可获得无敌帧，用来躲下一波弹雨。 需要无敌帧时可主动吃金弹，再继续输出。
短距激光 + 晕 短距激光可晕人。 pin BGB 时别贴太死；分开 pin 时留意激光范围。
属性 弱毒。几乎站桩（Speed 0）；击退阈值约 3 万。 相对更好 pin；仍要防弹雨与激光。

老大（The Boss）

技能 / 现象效果应对
出场时机 A+B 合血掉到约一半后刷新；A/B 会继续打到死。 注意刷新位置；有人负责 pin、有人转火。
蓝风（Blue wind） 脚下出现蓝风提示。 下马 / 离开该格。
紫圈 / 紫云（Purple area / cloud） 身边大紫圈；pin 在角落时范围可盖到大约 地图 2/3。 下马躲开；分边打时注意另一侧紫云扫射。
1/1（血蓝打成 1） 仍存在，会把血蓝打成 1。 立刻灌超级药水；有圣灵之盾（HS）更稳。
召唤小怪（Summons） 会周期性刷出多类小怪（数值见 召唤小怪）。可回血、加速、加防；另可召出带诱惑的女老板型。 至少 2 名可靠 cleave；控不住召唤往往等于团灭节奏。
属性 / pin 无元素弱；击退约 4 万；回避 60。 命中要够；pin 门槛不低。

女老板（Anego / Female Boss）

技能 / 现象效果应对
半图跳跃诱惑（Jump seduce） 朝她面向方向半图跳诱惑；大约 30 秒一轮。 尽量分开点杀；备圣灵之盾 / 勇士的意志（Will）；鸟笼优先点她。
刷新 由老大召唤进场。 刷出时转单体点杀。
属性 弱雷 / 圣；HP 约 7500 万；击退 1000。 圣/雷输出有效；击退低，好推离人群。
全场通用： 伤害上限 11.5k；有 1/1；无触碰；柱子平台脚点已删；地图无自然刷怪；掉落要等 A、B、老大都死后才出。

已知召唤逻辑（实战）

  • 老大出场后开始刷召唤；小怪很肉，单一 cleave 往往清不完。
  • 召唤可互奶 / 给老大回血（约 5 万–50 万一跳）；可给附近怪加速；还可加防（Defense up）——没有破甲时更难清。
  • 可刷出带半图跳诱惑的女老板型召唤。
  • 召唤似乎有血量阈值：cleave 过猛、保镖还没死就把召唤血线压穿，会刷得更凶（召唤 spam）；血线太歪时反而需要单体去秒关键目标（如女老板）。

七步流程

1
确认次数与门票/路线（新叶城保镖入口）。队里说好谁 pin、谁 cleave、谁点 BGA。
2
开打后尽快把 保镖 A（BGA） pin 在角落；远程/船长保持距离输出。
3
保镖 B（BGB） 会下弹雨（约 10k 级）；船长等职业要算船耐久 / 下马吃弹。
4
优先压低 BGA 血量，促使 老大（The Boss） 更早出场。
5
老大同场时：有人继续 pin，其他人集火还活着的保镖；注意召唤怪血线，别 cleave 过猛提前刷满召唤。
6
BGA 死后改 pin / 点 BGB；BGB 死后集火老大。
7
女老板（Anego） 出现时尽量分开点杀（单体 / 鸟笼）；同时躲老大的蓝风与紫圈。

前置与次数

  • 地点：新叶城（NLC）保镖相关副本入口（具体 NPC / 地图以游戏内为准）。
  • 次数：社群讨论里 BGA 曾长期是每日 1 次（相对多数 Boss 每日 2 次）；以当前补丁为准。

编制（2025 后口令）

刚需倾向

  • 能持续 cleave 的近战（英雄 / 黑骑士 / 冲锋队长等，以队内面板为准）
  • 能冲刺重新 pin 的近战（脱 pin 时的保险）
  • 有人专门盯保镖 A 的仇恨与血线

加分

  • 神射手（BM）：脚筋等工具，远程里更受欢迎
  • 船长（Corsair）：鸟笼点 BGA→BGB→女老板；章鱼补伤
  • 主教：容错；全场弱毒，毒系魔导也有发挥
  • 箭神穿透等单体窗口（血线歪了要秒某个目标时）

常见人数

  • 常见 3–4 人
  • 人越少越依赖 pin 与不吃弹雨失误
  • 隐士（NL）可打，但常需额外 cleave 位搭配；主持人未必优先收
现行偏 cleave；远程仍可打。招人常见 melee / cleave preferred。

阶段打法要点

1. Pin

  • 目标：把保镖 A pin 在角落，输出在安全距离打。
  • 脱 pin：近战冲过去重新 pin；未 pin 住时输出先停，避免把它打向人群。
  • 别站进它的出拳范围——拳可能扫到整队。

2. 保镖 A + B 同场

  • 优先蛋/鸟/点 BGA（刷新老大、控晕）。
  • BGB 弹雨约 10k；船耐久有限，可用下马吃弹 / 金弹无敌帧续船。
  • 双方防御都很高：召唤物（如章鱼）价值大。

3. 老大进场

  • 常见策略：有人 pin 住老大或控场，其他人先清还活着的保镖，再集火老大。
  • 注意召唤血线：cleave 过猛可能在保镖没死前刷出过多召唤，英雄舞等技能一次只能打有限目标，会变丑。
  • 攻击提示：脚下蓝风、身边大紫圈——下马/躲开。

4. 女老板

  • 尽量与主人群分开，用单体点掉。
  • 船长：尽量鸟笼点上；第一只可考虑苹果覆盖后两波。
  • 鸟笼没点上：用心停等爆发 + 鱼雷等范围技补，同时继续躲老大。

附录 · 船长（Corsair）在 BGA

船长在本战的操作要点。

  1. 船破后：远处连射（Rapid Fire），章鱼好了就放；角落放章鱼方便 cleave 维持 pin。
  2. BGA+BGB：鸟笼优先 BGA；尽量保持章鱼。BGB 弹雨：未上船吃第一下再上船，打约 3 炮后完美下马吃弹再上船；见金弹则撞金弹拿无敌帧，计数改为约 5 炮。
  3. 老大出现：蓝风/紫圈下马躲；同时躲 BGB 很难，尽力而为。
  4. BGA 死：鸟笼改 BGB，早脱弹雨监狱。
  5. BGB 死：船长进入舒适区——鸟笼老大、章鱼、躲技能。
  6. 女老板：请队友别瞬秒，留鸟笼窗口；点上则心停/苹果集火。
